## 🚀 What I've Shipped in Production

- **Company Operations Platform (250+ employees):** Built full-stack features for a React, TypeScript, and Supabase platform unifying project delivery, finance, staffing, and hiring, with 7-role access control and integrations with BambooHR, NetSuite, Jira, GitHub, and KnowBe4.

- **AI Hiring Pipeline:** Developed an AWS Bedrock-powered candidate screening and interview scheduling pipeline, reducing time-to-decision from 2–3 weeks to 4–5 days. Monitored AI workflows using self-hosted Arize Phoenix.

- **AI Courtroom Hearing Portal:** Led backend development using FastAPI and Node.js for judicial departments across 3 US counties, supporting approximately 10 daily hearings with speaker-identified transcripts, notes, action items, and an AI-powered chatbot.

- **Multi-Agent HR Copilot:** Built LangGraph-based workflows for candidate registration, challan generation, payment verification, and automated notifications across 9 monthly exams in 3 cities, each handling 500+ registrations.

- **Academic Compliance Assistant:** Developed an AI assistant that analyzed 45–50 documents per course against Bloom's Taxonomy matrices for UAE accreditation audits.

- **Agentic RAG Framework:** Built a LangChain, LangGraph, and ChromaDB-based framework for multi-hop question answering, using iterative retrieval, query reformulation, and reranking across production RAG applications.
